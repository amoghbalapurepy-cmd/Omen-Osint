# Security Policy

## Supported Versions

OMEN is currently under active development. Security fixes are prioritized for the latest version on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in OMEN, please report it privately rather than opening a public issue.

For vulnerabilities that could expose API keys, sensitive data, enable unauthorized access, or otherwise affect users or systems, use GitHub's private vulnerability reporting/security advisory features when available for this repository.

Please include:

- A clear description of the issue.
- The affected file, component, or endpoint.
- Steps needed to reproduce the issue, if safe to provide.
- The potential security impact.
- Any relevant logs or screenshots, with secrets and personal information removed.

Please do not include real API keys, passwords, tokens, private personal information, or other sensitive credentials in a report.

## Responsible Disclosure

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing technical details.

OMEN is intended for defensive security research, privacy awareness, and authorized testing. Reports involving unauthorized access to systems or data should not include or encourage further unauthorized activity.

Thank you for helping improve OMEN's security.
